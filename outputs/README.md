# Generated outputs

Reproducible analysis artifacts are organized as follows:

- `figures/`: response distributions, factor boxplots, daily time series,
  correlations, main effects, the three hour-interaction plots, and test
  predictions;
- `tables/`: machine-readable descriptive summaries, one-way and factorial ANOVA,
  model sequence, Tukey contrasts, response-scale screening and test metrics,
  diagnostic tables, VIF, and ACF/PACF;
- `diagnostics/`: response-scale residual and Q–Q panels, residual ACF and PACF,
  and the leverage/Cook's-distance plot.

`results_summary.md` and `resumo_resultados.md` provide readable summaries of
the final results. All artifacts are regenerated by `make all` and versioned so
that reproduction can be verified. Temporary artifacts belong in `outputs/tmp/`
and are ignored by Git.
